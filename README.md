🌐 JobQuest

✨ Empowering Job Seekers & Recruiters on One Platform

JobQuest is a modern MERN stack job portal that connects job seekers and recruiters effortlessly.
It features secure authentication, resume uploads, and a smooth user experience powered by RESTful APIs.

🌍 Live Demo :  🔗 [https://jobquest-tushar.onrender.com/]

🚀 Features

🔐 JWT Auth – Secure login & sessions

📄 Multer + Cloudinary – Resume upload & storage

🧑‍💼 Two Roles – Job Seekers & Recruiters

⚡ Fast APIs – Express + MongoDB

🎨 Responsive UI – React + Tailwind

---

🧩 Tech Stack

Frontend: React, Tailwind CSS

Backend: Node.js, Express.js

Database: MongoDB Atlas

Auth: JWT

File Uploads: Multer, Cloudinary

---

⚙️ Deployment: Push code to GitHub -->Connect repo on Render

MONGO_URI= ""
